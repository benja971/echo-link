Mode: Operate. Build directly in Svelte and CSS. No raster mockup or illustrative asset needed for this utility interface.

Confirmed choices: replace Catppuccin, keep English, prioritize uploading, limits and recoverable links. User delegated implementation of the complete audit backlog.

Visual authority: replace the previous decorative world. Preserve the product name and working capabilities. A subtly green-tinted light canvas and a graphite-neutral dark canvas, blue/teal/amber/rose action accents, Geist for the interface and monospace only for URLs, metadata and keyboard notation. No dotted background, colored halos, giant logo or automatic tip ticker.

First viewport: small brand/navigation, direct Share a file heading, practical explanation, file-selection area with a visible Choose files action. Desktop puts explanation and input side by side. Mobile uses a short heading and one sentence, a 160px file chooser on the homepage and an 88px chooser in the workspace. It is composed for a phone, not a stack of desktop sections. Anonymous limits follow the input, results remain in the same area with a selectable URL and explicit copy/open actions.

Signature interaction: a dropped, pasted or chosen file becomes a recoverable link. Clipboard success is a separate outcome. Multiple uploads retain each result, including partial failure.

Cross-surface rules: main action visible, 44px touch controls, content-driven wrapping, readable metadata, native modal behavior, useful status/error announcements, no hover-only function. Text links are accented and underlined at rest, with thicker underlines on hover/focus. Buttons have visible hover and active states; hover applies only on hover-capable devices. Primary states mix the accent with black in light mode or white in dark mode. The dropzone changes its surface and CTA together; file tiles receive a 3px inset accent border on hover. Mobile keeps account and selection controls.

Motion: only short feedback and bounded file-row arrival. Reduced motion removes row movement and spatial toast transitions, preserving state changes. Tips advance only by explicit user action.

Quality and proof: 320/390/768/1280 widths, native keyboard activation, modal focus confinement/restoration, upload success/refusal/partial failure, copy fallback, theme migration, text contrast and long titles. No assertion of screen-reader or physical-device certification without a real test.

Risks: intentionally familiar utility layout; no claim of a novel brand identity. Native browser behavior still needs representative Safari/Firefox and physical-device checks. Account data and configured limits remain real, not promotional inventions.
